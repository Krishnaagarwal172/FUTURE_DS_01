# Business Sales Dashboard - Task 1

This project is part of my Data Science & Analytics Internship at Future Interns.

## 📊 Project Overview
In this task, I analyzed business sales data using Excel and created a dashboard to understand sales and profit trends.

## 🔧 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts

## 📈 Key Insights
- Technology category generated the highest sales
- Office Supplies also contributed significantly
- Furniture has comparatively lower sales
- West region generated the highest profit
- Central region has the lowest profit
